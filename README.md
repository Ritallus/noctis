# Noctis · Genshin Planner

Устанавливаемое PWA-приложение без сервера и без ввода паролей HoYoverse.

## Запуск

Для локального тестирования: в папке проекта выполните `python -m http.server 8080`, затем откройте `http://localhost:8080`. Для установки PWA в браузере используйте кнопку «Установить» или меню браузера. Для доступа с других устройств разместите папку на HTTPS-хостинге (например, GitHub Pages / Netlify / Cloudflare Pages). Просто открыть `index.html` как файл можно для просмотра, но service worker и установка PWA требуют localhost или HTTPS.

## Возможности

- Импорт JSON с массивами записей молитв (распространённые варианты UIGF и Paimon.moe); объединение по ID.
- Pity по категориям баннеров и история последних молитв.
- Расчёт круток и максимальных расходов на созвездия.
- UID, ссылка на Enka.Network и попытка чтения публичного API (зависит от CORS и доступности).
- Ручной список персонажей, материалы, калькулятор смолы.
- Локальное сохранение и JSON-резервные копии.

## Ограничения

Форматы экспорта могут различаться; некоторые варианты UIGF/Paimon.moe потребуют доработки импортера. История не определяет автоматически гарант 50/50. Автоматическое получение профиля Enka может быть заблокировано CORS. Нет полной синхронизации инвентаря, детального справочника материалов и автоматического расчёта ресурсов по персонажам. Данные не синхронизируются между устройствами без ручного экспорта/импорта.
